1. Executive Summary

The OpenSpace WhatsApp AI Assistant is an enterprise-grade automated agent designed to provide instant, 24/7 financial support, onboarding assistance, loan intake, agent banking guidance, and dispute management for OpenSpace customers via WhatsApp.

By pairing Baileys (direct WhatsApp Web multi-device WebSocket protocol) with high-performance LLM inference via the Groq API, the bot delivers sub-second response times with zero monthly API markup fees, strict slot-filling state machines, and complete data privacy.

5. Conversational Flow & State Machine

The assistant employs a multi-tiered routing process to resolve user intent:

  1. Direct Pattern Matching: Incoming queries are evaluated against data/faq.json regexes. If a direct match is found (e.g., support hours, contact info), the templated answer is returned instantly without querying the LLM.
  2. Intent Classification (LLM): Unmatched queries are processed by the LLM in structured JSON mode to categorize user intent:
    • DISPUTE $\rightarrow$ Enters multi-turn dispute flow.
    • INQUIRY $\rightarrow$ Enters multi-turn loan/product application flow.
    • TX_STATUS $\rightarrow$ Executes transaction status stub.
    • HANDOFF $\rightarrow$ Checks business hours and escalates to human agents.
    • GENERAL $\rightarrow$ Returns conversational AI answer.
  3. Slot-Filling Guided State Machine: If inside a flow, the agent prompts for missing fields one-by-one (Amount, Reference, Name, Email) and confirms completion with an official reference ID.

6. Security, Compliance & Deployment

  • Zero Hardcoded Credentials: All keys and endpoints are configured exclusively in .env.
  • Private Auth State: The WhatsApp session directory (auth_info_baileys/) is excluded from version control in .gitignore.
  • Operating Schedule: Built-in awareness of West Africa Time (WAT) operating hours with automatic offline escalation.
